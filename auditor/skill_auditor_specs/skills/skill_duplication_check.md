## Rules

1. Read every skill file listed in the skill's Reference section.
2. For each rule in the skill, check whether the same instruction already exists in any of those referenced skills.
3. A rule is a duplication if it restates the referenced skill's content verbatim or paraphrased, even with different wording.
4. Flag each duplication: rule number and one-line explanation.
5. "apply [path]" is always sufficient — never flag it as duplication.
