## Rules

1. A skill document contains only these sections: **Rules → Context → Reference**.
2. All sections are optional — include only those that add value. Do not fill for completeness.
3. **Rules:** concrete instructions, one per line, numbered. Forbidden: explanations of why, repeating what a referenced skill already covers.
4. Every rule must prevent one concrete failure; delete rules that do not.
5. **Context:** when and where the skill applies. 1-2 lines max.
6. **Reference:** input/output examples or paths only if format matters. Omit if rules are self-explanatory.
