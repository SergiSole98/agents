# Execute implementation steps

## Context
Use while applying the approved plan to the project.

## Rules
1. Execute one plan step at a time.
2. Make the smallest change that satisfies the current step.
3. Keep changes inside the files and folders required by the plan.
4. Use existing tools and project conventions when available.
5. Record each completed step for the final report.
6. If a command or edit fails, inspect the cause before retrying.
